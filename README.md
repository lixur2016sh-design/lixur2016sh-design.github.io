1. 将 `index.html` 上传到你的 Pages 来源目录（根目录或 `docs/`）。
2. 确保同目录下已有 `share_ai.html`（若没有，请上传我之前给你的交钥匙包中的 `share_ai.html`）。
3. Commit 后等待 30–60 秒，访问站点首页即可看到效果。
